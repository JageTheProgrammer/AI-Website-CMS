# Security Policy

Polityra CMS is under active development. Security reports are welcome for the
latest version and supported deployment configurations.

## Reporting a vulnerability

Please report suspected vulnerabilities privately to the project maintainers.
If private vulnerability reporting is enabled for this repository, use the
repository's **Report a vulnerability** option. Otherwise, contact the
maintainers through the Polityra organization. Do not publish exploit details,
credentials, or personal data in a public issue.

Include a description of the affected component, the impact, and steps to
reproduce the behavior when safe to do so. You may report without a working
exploit. Please allow maintainers reasonable time to investigate and coordinate
a fix before publicly disclosing the issue.

## Scope and response

Reports about the web app, API, desktop app, shared packages, and project
deployment configuration are in scope. Third-party services and dependencies
should be reported to their respective maintainers as well when appropriate.

Maintainers will acknowledge and assess reports as resources allow. There is
no guaranteed response or remediation timeline.
